# Bundled Hindi typefaces

Unmodified variable fonts from the Google Fonts repository, retrieved 2026-10-04.

- Noto Sans Devanagari: https://github.com/google/fonts/tree/main/ofl/notosansdevanagari
- Noto Serif Devanagari: https://github.com/google/fonts/tree/main/ofl/notoserifdevanagari

Each font is distributed under its included SIL Open Font License. Local CSS family aliases keep the selected book design independent of operating-system fonts.
